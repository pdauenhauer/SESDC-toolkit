# Preact Setup via Vite

## Setup:
1. cd frontend
2. npm install
3. npm run dev

## Requirements:
1. Have a .env file in the root of the frontend folder. Here are the list of env variables you need:
```
VITE_FIREBASE_API_KEY
VITE_FIREBASE_AUTH_DOMAIN
VITE_FIREBASE_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET
VITE_FIREBASE_MESSAGING_SENDER_ID
VITE_FIREBASE_APP_ID
```
